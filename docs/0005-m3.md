# M3: moderation

Moderators review flagged and triaged items, act on them, and log every
action publicly. AI triage reads every new submission and comment. The design
is in `0001-design.md`, section 9.

## One way in

Every submission and comment enters the index through one function, whether
it comes from the web form or, from M4 on, from hydrant. A record written
straight to a PDS gets the same checks and the same triage as one written
through Threaded.

`accept` takes the author, the item, and its record URI and CID. In order, it:

1. Refuses banned DIDs and accounts whose level cannot post the item.
2. Applies the rate limits by level (design doc, §8).
3. Applies the tag rules: unknown tags dropped; no known tag left means not
   indexed; `show` needs `authored`; `ask` is text only; privileged tags.
4. Sends a URL posted in the last 30 days to the existing story.
5. Inserts the index row, or updates it when the record URI is already
   indexed. Threaded's own writes come back through hydrant, and they must not
   be indexed twice.
6. Adds the item to the triage queue in the same transaction.

The web handlers in `crates/web/src/write.rs` keep the parts that need a
person: the form, the PDS write, and deleting the record when `accept`
refuses or fails. The checks themselves move out of the handlers.
