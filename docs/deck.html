atproto OAuth

Sign in with your handle

Threaded is a confidential client: PAR, PKCE, DPoP, and an ES256 client assertion.

1

Enter a handle

Suggestions appear as you type. Resolve handle to DID, DID to PDS, PDS to its authorization server.

2

Pushed request

PAR with PKCE challenge, DPoP proof, and signed client assertion.

3

Consent at the PDS

The user approves the scopes on their own server.

4

Callback

Exchange the code. Reject unless sub equals the resolved DID and scope includes atproto.

5

Session

Tokens and DPoP key stay server-side. The cookie holds a session key only.

Sorting

Rank that decays with age

Ten times the score holds a story level with one 22 hours newer. Stored on the row, so every listing is an index scan.

base    = sum(tag.rank_boost) + (authored link ? 0.25 : 0)
cpoints = base < 0 ? 0
        : min(0.5 * sum(comment.score + 1), max(score, 0))
order   = log10(max(|score + 1| + cpoints, 1))
rank    = order * sign(score) + base + created_at / 79200

Capping cpoints at max(score, 0) keeps a negative
score's full weight, so flagged stories sink.

Moderation

Flags in, public log out

Flags

A downvote with a reason

Stories: off-topic, already posted, broken link, spam. Comments: off-topic, me-too, troll, unkind, spam. Three flags send an item to the queue. Flags stay private.

Actions

Every action is logged

Remove, restore, edit, merge, lock, ban by DID, grant role badges and roles. Notes on users stay private to moderators.

Lookahead

A real combobox

The WAI-ARIA combobox pattern in the light DOM: aria-activedescendant on the input, a listbox of options, and a status line that announces the count.

Prior art

Why not actor-typeahead

Its list sits in a closed shadow root. ARIA ID references cannot cross that boundary, so screen readers hear no suggestions.

Testing

Automated and by hand

make a11y in CI. Before each milestone ships: VoiceOver, NVDA, keyboard only, 200% and 400% zoom.

Build

Two processes, three places on disk

process

threaded

Web server, stream consumer, triage worker. Reads and writes the SQLite file; reads the blog folder.

process

hydrant

Indexes and backfills at.threaded submissions, comments, and votes into its own database. Talks to threaded over a Unix socket.

files

Blog folder

Markdown posts with YAML front matter. Picked up within a second of any change.

threaded

Binary

serve and seed. One executable, run by systemd behind nginx.

core

Logic

Ranking, levels, search grammar, link canonicalization, tag rules.

store

SQLite

sqlx, WAL, FTS5 indexes kept by triggers, forward-only migrations.

web

axum

askama templates, server-rendered, works without JavaScript. Blog loader.
